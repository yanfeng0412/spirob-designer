公式、来源与模型边界

SpiRobs 原论文（中国科学技术大学，Wang / Freris / Wei） · Device 正式版

ρ = a exp(bθ)；ρc = a[exp(2πb)+1] exp(bθ)/2
tan(φ/2) = b tanh(πb)/√(1+b²)
Dbase,包络 = Dtip + 2L tan(φ/2)
ρc,tip = Dtip / [2 tanh(πb)]
Θ = ln[1 + Lb/(ρc,tip√(1+b²))]/b
Δθ = Θ/N；β = exp(bΔθ)，根→尖缩放为 1/β
原螺旋与中心螺旋在相邻射线的交点形成四边形；沿中心弦局部轴旋转，生成轴对称单元。

公式对应论文式 (1)–(9) 的几何关系。三线：旋转生成单元及中心弹性轴；四线：本工具添加的均布孔改型，非原论文四线验证结果。孔偏心比例、孔径由用户选定。中心轴以锥形轴近似。未实现论文三线截面的二次切削。

OpenSCAD 导出的是直线展开的单体候选几何，含柔性轴、独立旋转单元与贯穿绳孔，可在 OpenSCAD 按 F6 后导出 STL。需核查槽口、尖端固定、底座固定和打印制造条件；本工具没有有限元或碰撞验证。旋转单元边界按离散弦构造；拉索预览为相邻孔位直线连接。

图中的圆点与截面是数学离散节点，不是需要安装电机的机械关节。所有拉索贯穿全臂并固定末端，不构成独立分段控制。
